# Comandos principales de Git utilizados

- `git clone`: Clona un repositorio remoto en la máquina local.
- `git checkout -b <rama>`: Crea y cambia a una nueva rama.
- `git status`: Muestra el estado de los archivos en el repositorio.
- `git add <archivo>`: Agrega cambios al área de preparación (staging).
- `git commit -m "mensaje"`: Registra los cambios en el historial.
- `git push origin <rama>`: Sube la rama al repositorio remoto en GitHub
